# Hero clips (supplier thread: "Подобрать анимации героя в Fal AI")

All clips are retargeted onto the hero skeleton (assets/models/hero.glb, Mixamo names), in the same per-clip format as pipeline/motion/retarget.mjs: `{fps:30, frames, tracks:{Bone:[x,y,z,w,...]}, hips:[x,y,z,...]}`. Drop the file into the directory you pass to pipeline/motion/pack.mjs and add the moves.json line shown.

Conventions: every clip faces +Z at frame 0 (as the hy_* clips), hips start at x=z=0, y = hips height above the floor. Real mocap (CMU) plays at native speed: use speed 1 (the hy_* clips needed 1.2-1.75 only because Hunyuan stretches time). Mocap needs little smoothing: smooth 1.

QA on every clip (pipeline/clips/fk.mjs): knee check is geometric (normal of thigh x shin vs the hip line), axis-free; 0 frames bend backwards in every delivered clip. footSlide = mean horizontal speed of a foot near the floor. Contact sheets (side / front / top stick figures) and real-mesh renders on the hero (<clip>_hero.jpg, 3/4 and side rows) are in clips/sheets/.

Sources: CMU Graphics Lab Motion Capture Database (free for any use, incl. commercial). bed_* = Hunyuan Motion (12 clips, about $1, screened; 2 of 12 rejected: one did not move, one did not roll).
