# NOTES-perf — производительность (owner: Optimization thread)

## Инструменты
- `game/perf.js` — экранный счётчик FPS (3 быстрых тапа по часам, клавиша F или `?fps`; запоминается на устройстве) и общий регулятор качества.
- Регулятор: `window.__perf.addStep(name, down, up?, order)`. `down()` упрощает (вернуть `false`, если нечего), `up()` возвращает (не передавать для необратимых шагов). Меньший `order` срабатывает раньше. Цель 60 FPS: ниже 46 за 2 с → следующий шаг; выше 57 в течение 12 с → откат последнего обратимого шага; если откат тут же снова проваливается (<25 с), регулятор фиксирует уровень.
- Текущие шаги (по порядку): dof 5 (camera.js) · bloom 10 · lights 15 (фонари без теней) · px 20 (1.5→1.3) · sunShadow 30 (тень солнца каждый 3-й кадр) · fog 40-42 (env.degrade, необратимо) · winGlow 45 (Lights: свечение окон) · lights 50 (без теней ламп) · px 60/70 (→1.1→1.0).
- `window.__perf.stats()` — fps, ms, p95, worst, js, calls, tris, pr, level, applied, hist.
- `tests/perf_profile.js [url] [png]` — draw calls/треугольники/JS на кадр через перехват WebGL, вес загрузки, скриншоты день/ночь (эмуляция iPhone 13; `DESK=1` — десктоп).
- `tests/perf_breakdown.js` — разбор сцены по группам: меши, треугольники, кто бросает тень, материалы, источники света.
- Облачный swiftshader рендерит на CPU (~0.2 FPS): реальный FPS iPhone только со счётчика у Павла.

## Предложения владельцам (переданы через координатора)
- Props: слить статичные меши между предметами одной комнаты по общему материалу; `castShadow=false` мелочам < 15 см (крючки, банки, инструменты на щите, книги) — их тень меньше 2 текселей карты 1024 на 24 м.
- Character: облегчённый меш героя для телефона (12-15k вместо 41k), убрать неиспользуемые клипы из hero-glb/hero-moves.
- Lights: на телефоне держать ≤8 точечных источников в сцене; навсегда выключенные — убирать из сцены (не intensity 0).
- Ground: трава — меньше лезвий в пучке на телефоне или затухание по расстоянию.
- Camera: DOF на телефоне по умолчанию выключен, пока нет цифр с iPhone.
